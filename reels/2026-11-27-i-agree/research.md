# Research — B1 "I am agree" ✗ → "I agree" ✓

## Claim checklist
| Claim in the video | Verified | Source |
|---|---|---|
| *agree* is a verb; present simple forms are "I/you/we/they agree", "he/she/it agrees" | ✓ | Oxford Learner's Dictionaries, *agree* (verb): https://www.oxfordlearnersdictionaries.com/definition/english/agree |
| "I agree with you." is correct and natural | ✓ | Oxford Learner's ("I totally agree with you!"); Merriam-Webster Learner's ("I agree with you."): https://www.merriam-webster.com/simple/agree |
| "I am agree" is a common learner mistake | ✓ | EPALE (European Commission) "Common Grammar Mistakes": https://epale.ec.europa.eu/fr/node/379217 ; Jakub Marian: https://jakubmarian.com/i-am-agree-vs-i-am-of-agreement-vs-i-agree-in-english/ |
| Don't add am/is/are before *agree* in the present simple | ✓ | Follows from *agree* being a full verb (Oxford); EPALE gives "I agree" / "I do not agree" / "Do you agree?" |
| "Do you agree?" (question form) | ✓ | EPALE; Merriam-Webster ("…don't you agree?") |
| "She doesn't agree with me." (negative, 3rd person) | ✓ | Pattern "agree with somebody" (Oxford); negative with do/does (EPALE "I do not agree"); Oxford example "We don't always agree about everything." |
| "She isn't agree" is wrong | ✓ | Same rule as above |
| British Council phrases: "Yes, I agree!", "I don't agree!" | ✓ | https://learnenglishteens.britishcouncil.org/exams/speaking-exams/agreeing-disagreeing |
| Kazakh: *етістік* = verb | ✓ | Wiktionary, етістік: https://en.wiktionary.org/wiki/етістік |
| Kazakh: *келісу* = to agree | ✓ (owner, please confirm) | jmarian.com Kazakh glosses (accord → келісу; келісім = agreement): https://jmarian.com/kk/en-accord ; Babel Free (келісім = consent, agreement) |

## Notes
- Deliberately NOT claimed: "never use *agreed* after *be*". "We are agreed" exists in formal British English, so the video only says "don't add am/is/are" to the present-simple verb.
- Why learners make it: Russian «я согласен» uses a short adjective, so learners map it to "I am agree". This is not stated on screen (not needed).
